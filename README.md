# Christian Becker — Veranstaltungs- & IT-Dienstleistungen

Website für Veranstaltungstechnik-Vermietung, DJ-Service, Verkauf gebrauchter Technik und IT-Dienstleistungen (Webentwicklung für KMU).

Gebaut mit [Next.js](https://nextjs.org) (App Router), TypeScript und Tailwind CSS.

## Entwicklung

```bash
npm install
npm run dev
```

Seite läuft dann unter [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Deployment

Das Projekt ist für ein Deployment auf [Vercel](https://vercel.com) vorbereitet.
